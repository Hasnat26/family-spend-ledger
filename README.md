# Family Spend Ledger — Independent Version

Static React-free/PWA-ready starter for free hosting. Core data is stored in browser localStorage.

Features: dashboard, transactions, edit/delete, custom expense/income categories, custom beneficiaries/payment methods, budgets, JSON backup/restore, CSV export, responsive UI and PWA offline shell.

For PWA/service-worker testing, serve this folder with a local HTTP server. It can be hosted on GitHub Pages, Cloudflare Pages or another static host.

Important: the JSON backup from the Emergent version may use a different schema. A migration mapping can be added after you upload that backup.
