# Family Spend Ledger — Independent Version

Privacy-first local family income/expense tracker for free static hosting.

## Features
- Dynamic month and year selector
- Opening balance carried forward from all earlier months
- Monthly income, expense, net and cumulative closing balance
- Six-month income/expense trend chart
- Category expense chart
- Monthly history table
- Transactions, budgets, custom categories, beneficiaries and payment methods
- JSON backup/restore and CSV export
- Browser localStorage and PWA-ready shell

Personal financial data is not included in this public source repository. Each user's data stays in their own browser storage unless they export/share a backup.
